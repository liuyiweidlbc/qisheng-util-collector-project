## 4. 请求头 checksum 格式

请求中常见的 checksum 形如：

```
ZTIzZWM3ZTU5ZTg2ODA5MTI0MjQzOTQ5ZTA5NjdmMThhMzQyNGMxY2EzMjQ2YzI5NWFkY2Y4ZDg4NzMwMzE2ZXw4ODY4ZTI5LmFwcHxmZGUxNzBlMzM2MmU0MTdkODA0MTliOWMwZDE5MjI1N3wxNzcwODA3MzA1OTQ2fA==
```

### 4.1 编码方式

**Base64 编码**：原始内容为 `|` 分隔的字符串，整体 Base64 编码后得到上述 checksum。

### 4.2 解码格式

解码后为 4 段，用 `|` 分隔：

| 段 | 示例1 | 示例2 | 含义 |
|----|-------|-------|------|
| 1 | `e23ec7e59e86809124243949e0967f18a3424c1ca3246c295adcf8d88730316e` | `632c7e06b5244192d8fe47035531c48162388548d034f21976c696a0b341e21a` | 哈希值（MD5/SHA 等） |
| 2 | `8868e29.app` | `lueynemjuorlh8868.app` | 应用/域名标识 |
| 3 | `fde170e3362e417d80419b9c0d192257` | `fde170e3362e417d80419b9c0d192257` | 设备/用户 ID |
| 4 | `1770807305946` | `1769755585529` | Unix 毫秒时间戳 |

### 4.3 编码流程

```
原始字符串: hash|domain|deviceId|timestamp|
     ↓
Base64 编码
     ↓
ZTIzZWM3ZTU5ZTg2ODA5MTI0MjQzOTQ5ZTA5NjdmMThhMzQyNGMxY2EzMjQ2YzI5NWFkY2Y4ZDg4NzMwMzE2ZXw4ODY4ZTI5LmFwcHxmZGUxNzBlMzM2MmU0MTdkODA0MTliOWMwZDE5MjI1N3wxNzcwODA3MzA1OTQ2fA==
```

### 4.4 用途

- 请求签名 / 防篡改
- 会话或设备追踪
- 校验请求来源和时效（通过时间戳）

### 4.5 Python 代码

参见 `checksum_utils.py`，或使用以下代码：

```python
import base64
import hashlib
import time
from typing import Optional


def decode_checksum(checksum: str) -> dict:
    """
    解码 Base64 checksum 为字典。
    
    Args:
        checksum: Base64 编码的 checksum 字符串
        
    Returns:
        包含 hash, domain, device_id, timestamp 的字典
    """
    raw = base64.b64decode(checksum).decode("utf-8")
    parts = raw.strip("|").split("|")
    return {
        "hash": parts[0] if len(parts) > 0 else "",
        "domain": parts[1] if len(parts) > 1 else "",
        "device_id": parts[2] if len(parts) > 2 else "",
        "timestamp": parts[3] if len(parts) > 3 else "",
    }


def encode_checksum(
    hash_val: str,
    domain: str,
    device_id: str,
    timestamp: Optional[int] = None,
) -> str:
    """
    将 hash、domain、device_id、timestamp 编码为 Base64 checksum。
    
    Args:
        hash_val: 哈希值（如 MD5）
        domain: 应用/域名标识
        device_id: 设备/用户 ID
        timestamp: Unix 毫秒时间戳，默认当前时间
        
    Returns:
        Base64 编码的 checksum 字符串
    """
    if timestamp is None:
        timestamp = int(time.time() * 1000)
    raw = f"{hash_val}|{domain}|{device_id}|{timestamp}|"
    return base64.b64encode(raw.encode("utf-8")).decode("utf-8")


def generate_hash(data: str, algo: str = "md5") -> str:
    """生成哈希值，默认 MD5。"""
    h = hashlib.new(algo)
    h.update(data.encode("utf-8"))
    return h.hexdigest()


# 示例
if __name__ == "__main__":
    # 解码
    c1 = "ZTIzZWM3ZTU5ZTg2ODA5MTI0MjQzOTQ5ZTA5NjdmMThhMzQyNGMxY2EzMjQ2YzI5NWFkY2Y4ZDg4NzMwMzE2ZXw4ODY4ZTI5LmFwcHxmZGUxNzBlMzM2MmU0MTdkODA0MTliOWMwZDE5MjI1N3wxNzcwODA3MzA1OTQ2fA=="
    print(decode_checksum(c1))
    # {'hash': 'e23ec7e59e86809124243949e0967f18a3424c1ca3246c295adcf8d88730316e', 
    #  'domain': '8868e29.app', 'device_id': 'fde170e3362e417d80419b9c0d192257', 
    #  'timestamp': '1770807305946'}

    # 编码
    checksum = encode_checksum(
        hash_val=generate_hash("some_data"),
        domain="8868e29.app",
        device_id="fde170e3362e417d80419b9c0d192257",
    )
    print(checksum)
```

## 6. 提取脚本

`extract_index_info.py`：从 index.html 自动提取上述信息并生成请求头 x-checksum。

```bash
# 默认解析同目录 index.html
python extract_index_info.py

# 指定 index.html 路径
python extract_index_info.py /path/to/index.html
```

输出：页面地址、API 地址、x-checksum、以及用于请求头的 Base64 checksum。
