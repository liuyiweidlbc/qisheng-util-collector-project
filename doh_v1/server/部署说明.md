# 阿里云 DoH 部署说明（照做即可）

目标：在阿里云 Ubuntu ECS 上跑起 DoH，得到：

```text
https://你的公网IP/dns-query
```

**只走下面这一条「推荐路径」即可。** 文档末尾的「进阶」可以先不看。

---

## 你需要准备什么

| 项 | 要求 |
|----|------|
| 云主机 | 阿里云 ECS，系统 **Ubuntu 20.04 / 22.04**（x86_64） |
| 本机 | Windows，能 SSH / SCP 到这台 ECS |
| 本仓库文件 | 只用 **一个脚本**：[`setup_doh_dnsproxy_ubuntu.sh`](setup_doh_dnsproxy_ubuntu.sh) |
| 验证（可选） | 本机 Python3 + [`verify_doh.py`](verify_doh.py) |

下面把「你的公网 IP」一律写成 `47.120.51.123`，**请换成你 ECS 控制台里看到的公网 IP**。

---

## 第 0 步：阿里云安全组（先做，否则永远访问不到）

1. 打开 [阿里云控制台](https://ecs.console.aliyun.com/) → 你的实例 → **安全组** → **配置规则** → **入方向**
2. 确保有这两条（没有就手动添加）：

| 协议 | 端口 | 授权对象 | 用途 |
|------|------|----------|------|
| TCP | 22 | 你的办公网 IP，或临时 `0.0.0.0/0` | SSH |
| TCP | 443 | `0.0.0.0/0` | DoH（HTTPS） |

不做这一步，脚本装成功了，外面也连不上。

---

## 第 1 步：把安装脚本上传到 ECS

在本机 **PowerShell** 执行（路径按你本机仓库改；用户名一般是 `root`）：

```powershell
scp "d:\1.SoccerGambling\assistant\workspace\other\all_utils\all_util_project\doh_v1\server\setup_doh_dnsproxy_ubuntu.sh" root@47.120.51.123:/root/
```

成功后，服务器上应有文件：`/root/setup_doh_dnsproxy_ubuntu.sh`。

> 没有 `scp`？用 WinSCP / FinalShell 把同一个文件拖到 `/root/` 也行。

---

## 第 2 步：SSH 登录并执行安装

```powershell
ssh root@47.120.51.123
```

登录后在 **服务器** 上执行（整段复制）：

```bash
chmod +x /root/setup_doh_dnsproxy_ubuntu.sh
sudo /root/setup_doh_dnsproxy_ubuntu.sh
```

### 成功时你会看到类似输出

```text
==========================================
  DoH 已就绪（dnsproxy 单组件）
==========================================
  DoH 地址: https://47.120.51.123/dns-query
  ...
  阿里云安全组请放行入方向 TCP 443
==========================================
```

记下这行地址，后面验证和客户端都用它。

### 安装失败常见原因

| 现象 | 处理 |
|------|------|
| `下载失败` / 连不上 GitHub | ECS 需能访问外网；可换有外网的机器装，或手动下载 dnsproxy 二进制 |
| 提示不是 root | 用 `sudo` 或 root 账号 |
| 跑完但外面不通 | 回去查 **第 0 步安全组 443** |

### 在服务器上确认服务活着（可选）

```bash
systemctl status dnsproxy-doh --no-pager
```

应显示 `active (running)`。

---

## 第 3 步：在本机验证（必须做，确认真的可用）

回到 **Windows**，打开 PowerShell：

```powershell
cd "d:\1.SoccerGambling\assistant\workspace\other\all_utils\all_util_project\doh_v1\server"

# 若提示没有 dnspython / requests，先装：
pip install requests dnspython

# 把 IP 换成你的；-k 表示忽略自签名证书（本方案必须加）
python verify_doh.py -u "https://47.120.51.123/dns-query" -k
```

### 成功示例

```text
DoH 自建服务验证
...
  OK - x.x.x.x
```

看到 `OK` 即部署完成。

### 失败怎么查

| 报错 | 含义 |
|------|------|
| 连接超时 / 无法连接 | 安全组没开 443，或 IP 写错，或服务没起来 |
| SSL / 证书相关且你忘了 `-k` | 补上 `-k` 再测 |
| `400` 且提示装 dnspython | 执行 `pip install dnspython` 后再测 |

---

## 第 4 步：你得到了什么、怎么用

| 项 | 值 |
|----|----|
| DoH 地址 | `https://你的公网IP/dns-query` |
| 证书 | 自签名 → 多数客户端要「跳过证书校验」或导入证书 |
| 上游 DNS | 脚本里写死为阿里 `223.5.5.5` / `223.6.6.6` 与 Cloudflare `1.1.1.1` |

本方案解决的是：**服务器提供加密 DNS 查询接口**。  
Windows 本机系统全局走 DoH，见上级目录 [`../client/`](../client/)（与本次服务器部署无关）。

---

## 重新部署（覆盖安装）

同一台机器再装一次即可（会覆盖证书与服务配置）：

```bash
sudo /root/setup_doh_dnsproxy_ubuntu.sh
```

然后重复 **第 3 步** 验证。

---

## 常用运维命令（服务器上）

```bash
# 看状态
systemctl status dnsproxy-doh --no-pager

# 重启
sudo systemctl restart dnsproxy-doh

# 看最近日志
journalctl -u dnsproxy-doh -n 50 --no-pager
```
